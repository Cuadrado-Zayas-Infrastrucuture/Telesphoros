## Behavior evidence

The browser tier uses the repository's existing ephemeral PostgreSQL harness, real API authorization/membership, migrations, decision/follow-up writes and ledger. It signs in through the fake identity provider with actual RS256 tokens. Its upstream fixture preparation deliberately uses the existing recorded-text runner, stand-in reader and synthetic knowledge. The test application's object storage is in memory. These are disclosed test substitutes outside the downstream decision UI under test; they do not verify actual PDF extraction, report-reader accuracy, unseen layouts, S3 acceptance or clinical validity.

Baseline: the real patient page lacked Recorded results, and the browser test failed waiting for that button. An earlier setup attempt inherited `JEST_WORKER_ID` into Playwright and was refused before tests ran; it is not red/green behavior evidence. The child now has an independent browser environment. All eight initial desktop/mobile cases passed after implementation.

The uncertain-response case first commits through the real decision API, then deliberately replaces its HTTP response with a 503. Retry uses the exact original payload and stores only one decision. Author correction and withdrawal preserve the original entries and notes; the linked follow-up stores the server's current decision reference with the explicitly selected medication. A competing real API decision makes a stale form receive 409 while retaining its note. Reviewers have history without write controls, and a retracted evaluation has no new-decision control.

Mutation: removing eligibility from the decision-control guard caused both retracted-result cases to fail with `expected 0 controls, received 1`. The source was restored byte-for-byte before final checks. A further transport-failure case distinguishes a generic 503 from the explicit `PIPELINE_DISABLED` code and retries the actual read. A separate browser case on the storage prototype verifies the real disabled-processing response without claiming an empty evaluation list.
