## Found and fixed during verification

The first version of the aside linked the word "Reports". The owned-storage suite then failed in four places because the page had two links with the identical name "Reports" beside the navigation link, which is also ambiguous for screen-reader users. The link text is now "Reports page". The tests were not changed. A mobile column-width change that broke "synthetic.json" mid-word was also caught in the screenshots and reverted below the `sm` breakpoint.
