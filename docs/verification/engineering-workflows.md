## Evaluation method

The local checker evaluates 21 positive and 14 negative routing cases and validates metadata/local reference files. Before/after comparisons use the same frozen prompts and seven matched upstream/local workflow descriptions. This measures lexical discoverability, not actual model selection or compliance. It does not establish that an agent will obey an instruction under adversarial conditions.

Eight synthetic scenario rubrics cover approval continuity, missing service tiers, pipeline failure propagation, tenant review, rounded runner costs, source injection, release boundaries and incomplete producer listings. Walkthrough evidence is distinguished from independent agent evaluation. No independent model/subagent evaluation is authorized or claimed.

The checker tests create only fresh `telesphoros-workflow-*` temporary directories containing synthetic Markdown fixtures. Cleanup removes those test-owned files/directories; no checkout, service, credential or persistent dataset is in that blast radius. Fixtures can be regenerated by rerunning the tests.
