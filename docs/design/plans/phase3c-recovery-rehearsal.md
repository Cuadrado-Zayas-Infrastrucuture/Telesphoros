Record source `pg_database_size`, report-object logical bytes, plaintext dump and encrypted archive bytes, table/row/version counts, schema/backup identity and environment. Keep a bounded small-fixture procedure baseline; no production RTO or GB-scale claim.

Blast radius: the rehearsal creates and drops only its registered synthetic source/restore databases, one owned temporary target cluster, and owned temporary fixture files. Corruption controls run only there. Target cluster roles may be removed/recreated only in that owned cluster. No shared/production database, existing cluster, operational key or real storage version is modified. Fixture data can be regenerated from the committed setup; retained summary evidence survives cleanup. Never delete arbitrary paths or caller-named databases.

Exclusions: recovery architecture or backup-format changes, cryptography, retention, provider/BAA/custody, scheduling, independent report-file copies, Terraform, AWS, production data, clinical logic, deployment and spend. Database success plus bytes still on primary does not establish complete application recovery.
