# A result made with signed knowledge says that its wording is real and its patient fictional (spec 044, slice K2c)

Date: 2026-11-21

When a stored assessment's scope is `synthetic-patient-signed-knowledge` (an assessment of a synthetic patient against the signed, real
knowledge, spec 044 K2), the assessment result and each such evaluation in the patient's stored results show the founders' wording:
"Real CPIC guideline wording. Fictional patient. Not approved for clinical use." Results made with the synthetic knowledge show nothing new,
and the existing synthetic labels stay on every screen, since the patients are still synthetic. The Spanish wording is still to be written.
Frontend only; no route, schema or setting changes. The backend that stores this scope is slice K2a. The code was written without running
it here (founder decision P2); CI is its first run.
