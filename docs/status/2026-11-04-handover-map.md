# Hand-over map: the assessment in the docs, team access, an entry-link guard

Date: 2026-11-04

A fresh clone of `main` (4005ee76), set up by following only `docs/start-here.md` and `CONTRIBUTING.md` on macOS, Node 22.22.0 and pnpm 10.28.0, installed, passed every required local check and started the storage demo. What it could not give a newcomer was a map of the MVP's own feature and a statement of what they cannot do. This change adds both. Documentation and one CI-config test only.

What changed: [architecture.md](../architecture.md) has a section on the synthetic assessment (spec 032 S3) and no longer says nothing is applied in AWS; the [glossary](../glossary.md) adds structured revision, finding review, synthetic assessment and synthetic knowledge, and stops listing VCF as an accepted format; [product-capabilities.md](../product-capabilities.md) gains one dated row; the backend README lists the structured-preview and assessment routes; a new [team-access.md](../ops/team-access.md) says what the repository alone allows and what only the founder holds today (staging AWS, the private release folder, the scripts not yet ported, the reader engine, DNS, invitations, GitHub ownership); the [documentation map](../README.md) and `CONTRIBUTING.md` link to it; `STATUS.md`'s first line sends a newcomer to the map instead of calling itself the place to start. [database.md](../database.md) names a macOS trap: PostgreSQL 16 started with no `LANG` and no `LC_ALL` stops with "postmaster became multithreaded during startup" (reproduced on a disposable cluster; either variable fixes it), and the recovery suites start their own server. `.github/ci/doc-links.test.mjs` fails when a relative link in an entry page (80 pages, 793 links) names a missing file; dated records are not read. Its first run found six links in `infrastructure/docker/README.md` to logs under `/private/tmp` on the machine that produced them; they are now plain text.

Verification: the new test passes, and seven deliberate breaks (a broken link, a folder left out, existence never checked, code blocks read, anchors read as files, dated records read, root links resolved from the disk root) each turned it red, with every file restored byte-identical. Not done: the 66 broken relative links left in the repository, all in `docs/verification` (62 to logs under `/private/tmp`, 4 to missing preview images), stay as their records were dated; headings inside a page are not checked; the team-access steps (roles, ported scripts, agreements) are not taken.
