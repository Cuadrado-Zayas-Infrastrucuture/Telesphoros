# Knowledge signer key ids are the signers' handles
Date: 2026-11-10

The knowledge signing runbook now says each signer's key id is their handle, the same in `knowledge_signers`, `KNOWLEDGE_SIGNER_KEYS` and `knowledge:sign --key-id`, and that rotating a signer replaces their key under the same id, after which their files are signed again.

Documentation only; nothing is applied or signed.
