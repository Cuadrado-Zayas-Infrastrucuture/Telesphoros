# Support

This project is maintained by one person, on a best-effort basis. There is no service-level commitment.

- **Questions and bugs:** open a GitHub issue with the issue forms. Do not include patient data.
- **Security problems:** see [SECURITY.md](SECURITY.md). Never use a public issue.
- **Clinical use:** this software is not approved for clinical use, and this project cannot answer questions about clinical decisions.
- **Private reports** (security problems and conduct concerns only): security@cuadradozayasinfrastructure.com. It is not a support line; see SECURITY.md.
