# Draft tasks: medication–gene review flags

| Task | Owner | State / exit condition |
| --- | --- | --- |
| FG-1 | Founder/product owner | Appoint clinical signer; approve intended use and proposed decisions |
| FG-2 | Clinical signer + maintainer | Confirm clinical-source rights, signed content and exact RxCUI mapping contract |
| FG-3 | Clinical signer + independent reviewer | Approve source fixtures, hold matrix and clinical-validation protocol |
| FG-4 | Maintainer, after FG-1–3 approval | Plan separately reviewed gated implementation and MD-6 evolution; preserve capture-only default |
| FG-5 | Maintainer + reviewer | Implement and verify authorization, stale evidence, deterministic mapping, immutable evidence, holds and compact UI in the approved slices |
| FG-6 | Clinical signer + release approver | Sign off the specific validated version and intended use; separately approve deployment |

All tasks are open. No clinical signer or clinical approval is invented by this task list.
