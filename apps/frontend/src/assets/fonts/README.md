# Poppins

Poppins SemiBold was already part of the frontend. Poppins Regular was added for the product landing page from the official Google Fonts `ofl/poppins/Poppins-Regular.ttf`, reusing the unmodified asset from the founder-approved social-card work. Both are self-hosted and covered by the adjacent `Poppins-OFL.txt`. No runtime font service is called.

# Inter — landing page only

Inter Variable v4.1 is the founder-approved landing-page typeface (2026-10-14). The original WOFF2 was obtained from `rsms/inter`, tag `v4.1`, path `docs/font-files/InterVariable.woff2`; its SIL Open Font License is bundled as `Inter-OFL.txt`. Official project: https://rsms.me/inter/ .

Self-hosted in the landing stylesheet, with weights 100–900 and optical sizing enabled. The landing content, navigation and footer use the dedicated landing font token. The Poppins product wordmark, dashboard and other application routes retain their existing typography. No third-party font request or OpenAI Sans asset is used.
